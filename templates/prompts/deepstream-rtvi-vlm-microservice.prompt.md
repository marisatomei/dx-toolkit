Create a microservice for the RTVI VLM application. Follow the steps below to complete that.

- Create a FastAPI-based server and implement the following endpoints:
  - `POST /streams` — add a new RTSP stream source
  - `DELETE /streams/{stream_id}` — remove a stream source
  - `GET /streams` — list all active streams and their status
  - `GET /streams/{stream_id}/summaries` — retrieve recent VLM summaries for a stream
  - `POST /config` — update pipeline configuration (sampling interval, batch duration, Kafka settings)
  - `GET /health` — health check endpoint
- Create a Dockerfile to package everything together for Docker image generation.
- Create a deployment guide (`DEPLOYMENT.md`) to run the microservice.

**IMPORTANT**

- Generate production-ready code — do not create dummy implementations for any endpoint.
- Update the code in the `rtvi_app` directory if required for a working implementation of the endpoints.
- All endpoints must validate input and return structured error responses.
